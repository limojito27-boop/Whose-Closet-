# Whose Closet?

A seasonal outfit and costume prompt collection for character creation.

**Whose Closet?** is a browser-based wardrobe archive featuring outfit combinations for male and female characters. Explore clothing by season, browse sample images, and copy detailed English clothing prompts for AI image generation.

## Features

- **Men's & Women's Wardrobes** — Separate outfit collections for male and female characters.
- **Seasonal Collections** — Spring, summer, autumn, and winter wardrobes.
- **Special Outfits** — Partywear, costumes, holiday outfits, and themed clothing.
- **Outfit Prompts** — Detailed English prompts describing clothing, materials, colors, and accessories.
- **Random Colors** — Generate alternative color combinations instantly.
- **Sample Images** — Visual references for outfit combinations.
- **Copy Prompts** — Copy outfit descriptions for use in AI image generation.

## Getting Started

Visit the published website through GitHub Pages.

No installation is required. Open the website in your browser, choose a wardrobe collection, and explore the available outfits.

## How to Use

1. Choose the men's or women's wardrobe.
2. Select a season or outfit category.
3. Browse outfit combinations and sample images.
4. Use the random color feature to explore variations.
5. Copy your preferred outfit prompt.
6. Use the prompt in your preferred AI image generation tool.
